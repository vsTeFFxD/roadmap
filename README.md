ПРАКТИКА

Попробуйте сделать самую самую простую игру в стиле ООП+СЕРВИСЫ.

Напомню, что ООП может быть не в любой игре, а Сервисы должны присутствовать везде.


Сервисы - управляют определённой логикой. Например, есть отдельный сервис, который управляет квестами, другой сервис управляет Инвентарём.
